# 引用幻觉审计（Citation Hallucination Audit）

批量核验稿件参考文献的真实性，打 **CrossRef** 和 **DataCite** 双库实查，算出**引用幻觉率**。

零第三方依赖（纯 Python 标准库），回答一个问题：

> 这篇稿子的参考文献里，有多少条指向的东西**根本不存在**——或者存在，但**不是引文所说的那一篇**？

---

## 为什么需要它

大模型编造文献分三级，一级比一级难抓：

| 类型 | 长什么样 | 判定 |
|---|---|---|
| **纯幻觉** | 文献根本不存在，DOI 查无此号 | `NOT_FOUND` |
| **张冠李戴** | DOI 是真的，作者和期刊也对，但**题名是另一篇论文的** | `MISMATCH` |
| **存在但无关** | 文献真实，但支撑不了它被引的那句话 | 机器查不出，需人工 |

**中间那种最危险。** 编造的 DOI 通常格式就有毛病，肉眼扫一眼参考文献就能发现；而**一个能打开、
作者期刊全对、只是题名换成了别人的 DOI**，能骗过人工检查、骗过文献管理软件、骗过所有 DOI 语法校验器。
审稿人点开链接，看到的是一篇真实存在的论文页面——除非他逐字读题名。

本工具在真实稿件里抓到的实例（作者、期刊、卷期页、DOI 全对，只有题名是别人的）：

```
DOI            10.1002/sim.9884
数据库真实题名  Comparison of combination methods to create calibrated ensemble
               forecasts for seasonal influenza in the U.S.
稿件里的引文    Practical considerations of the FluSight multiseason influenza
               forecasting challenge
```

**没有任何文献管理软件会报警，但一次 API 调用就能查出来。**

## 安装

本仓库同时打包为一个 **skill**（WorkBuddy / Claude 风格的 agent 技能）。

```bash
git clone https://github.com/JonasTaube/citation-hallucination-audit.git
cp -r citation-hallucination-audit ~/.workbuddy/skills/
```

也可以只用 `scripts/citation_audit.py`——它本身就是个独立的命令行工具。

## 用法

```bash
# 审计一篇稿件
python scripts/citation_audit.py manuscript.docx

# 额外输出 JSON 与 Markdown 报告
python scripts/citation_audit.py manuscript.docx --json report.json --md report.md

# 直接审计一段参考文献文本
python scripts/citation_audit.py --text "Smith J. Title. Nature. 2020;1:2. doi:10.1038/xxxxx"

# 批量（缓存跨稿件共享，重跑几乎瞬时）
for f in *.docx; do python scripts/citation_audit.py "$f" --json "${f%.docx}.json"; done
```

支持格式：`.docx`（直接读 `word/document.xml`，**不需要** python-docx）、`.txt`、`.md`、`.csv`。

| 参数 | 默认 | 说明 |
|---|---|---|
| `--interval` | `2.0` | 两次 API 调用之间的间隔秒数。建议 ≥1s，对 CrossRef 礼貌一些 |
| `--no-cache` | 关 | 禁用本地 `.citation_audit_cache.json` |
| `--json` | — | 输出完整 JSON 报告（汇总 + 逐条明细） |
| `--md` | — | 输出 Markdown 报告 |

**先设置你的联系邮箱**，否则 CrossRef 会把你当匿名客户端限流更狠：

```bash
export CITATION_AUDIT_CONTACT="you@example.com"
```

## 输出

```
====================================================================
引用幻觉审计报告
====================================================================

参考文献条目总数(启发式):        44
其中带 DOI 可自动核验:           41  (93.2%)
无 DOI，本工具未核验:             3  ← 需人工或题名反查

可核验引用条目 (唯一 DOI):        41

  [OK ] MATCH     真实存在，题名可对应      38
  [~~ ] REVIEW    题名部分吻合（疑变体/缩略） 1  ← 人工确认
  [!! ] MISMATCH  存在但题名不符（张冠李戴）  0
  [XX ] NOT_FOUND 全库查无此号（纯幻觉）     0
  [?? ] UNKNOWN   网络异常，无法判定         0

--------------------------------------------------------------------
★ 引用幻觉率 = (0 + 0) / 41 = 0.0%
--------------------------------------------------------------------
```

**口径**：`(MISMATCH + NOT_FOUND) / 可判定条目数`。
`UNKNOWN`（网络/限流查不到）**分子分母都剔除**——查不到不等于造假。

`REVIEW` 覆盖两种良性情况，**不计入幻觉率**：

- 题名部分吻合（副标题增删、英美拼写差异、截断）；
- 引文条目本身没写题名（如 `19. AJPM Focus 2026; 5: 100434.`）。

## 工作原理

```
定位参考文献段落
    → 正则抽 DOI、去重
    → 为每个 DOI 匹配它所在的完整引文条目（见下方「三个坑」）
    → GET api.crossref.org/works/{doi}
         ├ 200 → 与引文条目比对题名
         │        ├ ≥65%  → MATCH
         │        ├ 45~65% → REVIEW
         │        └ <45%  → MISMATCH
         └ 404 → GET api.datacite.org/dois/{doi}
                  ├ 200 → 同样比对
                  └ 404 → NOT_FOUND
```

题名吻合度取两个度量的**较大值**：

- `full` = 数据库题名词被引文条目覆盖的比例；
- `head` = 题名**开头 6 个实词**的命中率（专治"引文只写主标题、省略副标题"）。

只用 `full` 会把合法的缩略题名判成张冠李戴（实测踩过）。

### 为什么要查两个库

arXiv 的 DOI（`10.48550/arXiv.*`）和数据集 DOI（Zenodo、figshare）注册在 **DataCite**，不在 CrossRef。
只查 CrossRef 的实现会把每一篇 arXiv 引用都报成幻觉。

## 三个坑（血泪教训）

以下三个错误在开发过程中**各自造成过海量假阳性**，写自己的版本前务必知道。

**坑 1：不要按行切分引文条目。**
docx 转文本会把 `</w:p>` 变成 `\n`，常常把题名和它的 DOI 分到不同行。上下文因此为空，
整篇稿子会被判成 100% 幻觉。

**坑 2：绝不要用"DOI 前后固定字符窗口"当上下文。**
"取 DOI 前 260 个字符"在长题名上会失效——窗口伸进了**上一条**条目里。实测这一步把 30 条引用里的
28 条误报成张冠李戴，而它们全都是清白的。

**坑 3：有些引文条目根本没有题名**（如 `19. AJPM Focus 2026; 5: 100434.`）。
它们的题名吻合度必然是 0%——那是格式问题，不是题名被换。引文条目实词数 <6 时一律归入 `REVIEW`。

**可用做法**：把参考文献段压平成一整串 → 按编号边界 `(?=\b\d{1,3}\.\s+[A-Z])` 切分 →
把不含 DOI 的碎片并入前一条 → 每个 DOI 归属它所在的那一条 → 只有切不出 3 条以上时才退回位置窗口。

## 限流处理

CrossRef 对突发流量非常敏感，会直接回 HTTP 429。因此本工具：

- 在 User-Agent 里带 `mailto:` 进入礼貌池（polite pool）；
- 最多重试 5 次，指数退避 `sleep(3 * (attempt + 1))`；
- 默认调用间隔 2 秒；
- 每次查询都写入 `.citation_audit_cache.json`，**跨稿件共享**。

缓存的意义：137 条引文首轮跑了约 8 分钟，之后每次改完阈值重跑只要 **0.3 秒**。

---

## 能力边界（诚实标注）

- **只验证元数据。** 它能确认一条引文指向一篇真实且题名正确的论文；**无法判断**这篇论文是否真的支撑了引用它的那句话。
- **只覆盖带 DOI 的条目。** 无 DOI 的条目会被计数并报告，但不会核验。Vancouver 格式的参考文献表可能有
  一半条目被漏掉。
- **条目总数是启发式估计**，按编号模式推断，只能当近似值。
- **45/65 两个阈值可调、但非普适**，是按英文理工医文献标定的。其他格式请重新调整 `MATCH_T` / `REVIEW_T`。
- **`REVIEW` 仍需人工过目。** 工具的作用是把 60 条缩小到 3 条值得花两分钟看的，最终判断不代劳。
